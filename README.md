Это моя первая попытка создать приложение "для себя" исключительно с помощью нейросетей. Никакого ручного набора кода. Только вайбкодинг

# PassManager

Локальный менеджер паролей на Python с современным интерфейсом (PySide6),
шифрованием данных и синхронизацией через WebDAV.

## Запуск

Двойной клик по **`start.py`** (Windows/Linux).

При первом запуске программа сама установит нужные библиотеки
(`PySide6`, `cryptography`, `requests`) — в локальное окружение `.venv`,
а если его создать нельзя — в пользовательский каталог. Ручные шаги не нужны.

### Linux: диалог «Запустить файл или просмотреть?»

Это обычное поведение файлового менеджера (Cinnamon/Nemo). Чтобы обойти его,
используйте файл **`start.desktop`**: щёлкните по нему правой кнопкой →
«Свойства» → «Права» → отметьте «Разрешить выполнение файла как программы»,
после чего двойной клик сразу запускает программу.

### Linux: требуются библиотеки Qt (libxcb-cursor0)

Qt 6.5+ требует системную библиотеку `libxcb-cursor0`. Если её нет в системе,
окно не откроется. Программа уже содержит эту библиотеку в каталоге `libs/`
и подхватывает её автоматически, поэтому ничего доустанавливать не нужно.

Каталог `libs/` относится только к Linux (в нём лежат `.so`-файлы) и на других
системах не используется.

Если хочется поставить её системно (необязательно):

```
sudo apt install libxcb-cursor0
```

### Windows: окно консоли при запуске

При двойном клике по `start.py` система запускает его консольным
интерпретатором, поэтому на время первого запуска может мелькать окно
консоли (видно установку зависимостей). Приложение затем автоматически
перезапускается оконным интерпретатором (`pythonw.exe`), и окно исчезает.

Если нужно оставить консоль для отладки, задайте переменную окружения
`PASSMANAGER_CONSOLE=1` перед запуском.

## Возможности

- Сервисы и учётные записи (логин, пароль, комментарий, даты создания и смены пароля).
- Списки при открытии отсортированы по алфавиту (А→Я). Сортировку можно
  переключать кнопкой (сервисы) и кликами по заголовкам столбцов (записи);
  это только представление и между устройствами не синхронизируется.
- История изменения пароля для каждой учётной записи.
- Корзина: удалённые сервисы и записи хранятся без ограничения по времени;
  есть восстановление, удаление навсегда и полная очистка.
- Копирование логина и пароля в буфер обмена (буфер очищается через 30 секунд).
- Шифрование всего хранилища (AES-256-GCM, ключ из мастер-пароля через PBKDF2).
- Синхронизация с WebDAV: адрес, логин и пароль сервера задаются в настройках.
  Если сервер недоступен — работа идёт на локальной копии.

## Файлы

- `vault.txt` — зашифрованное локальное хранилище (текстовый файл).
- `config.json` — настройки. Пароль сервера хранится зашифрованным.
- `start.py` — точка входа.

## Структура кода

```
app/
  crypto.py     шифрование и вывод ключа из мастер-пароля
  models.py     модели данных и корзина
  storage.py    чтение/запись локальных файлов
  webdav.py     клиент WebDAV
  sync.py       слияние двух копий
  manager.py    прикладная логика
  ui/           графический интерфейс
  tests/        модульные тесты
```

## Тесты

```
python -m app.tests.test_core
```

Проверяют шифрование, хранилище, слияние, корзину и историю (без GUI).
